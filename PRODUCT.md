# AI Research Platform

## Register

product

## Users

Platform administrators manage accounts, projects and platform operations. Project managers coordinate datasets, research runs, findings and collaborators within a project.

## Product Purpose

Support research collaboration with clear project state, review workflows and traceable outcomes.

## Brand Personality

Clear, focused, informative. Admin and PM use the selected theme's colors, including the default black accent.

## Design Principles

- Make the next action and current state easy to identify.
- Give color a consistent meaning across Admin and project workspaces.
- Keep data tables readable and metadata subordinate to record names.
- Preserve existing APIs, permissions and modal forms when improving presentation.
- Reuse the local component system and support existing theme presets.

## Accessibility & Inclusion

Use text alongside status colors, visible keyboard focus, readable contrast, reduced motion and responsive layouts.
